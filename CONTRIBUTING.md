# Contributing

Thanks for helping improve the Reflection import adapters. This repo focuses on migration tools and documentation, not the Reflection product itself.

## Ways to contribute
- Fix or clarify docs and prompts
- Add or improve import adapters
- Report bugs with clear reproduction steps

## Before you start
- Search existing issues first
- For new adapters or major changes, open an issue to align on scope

## Development notes
- Keep scripts self-contained and easy to run
- Prefer clear, readable Python over cleverness
- If you add dependencies, document installation steps

## Pull requests
- Keep PRs focused and small
- Update docs and examples when behavior changes
- Include a brief test note in the PR description

## Data and privacy
- Never commit real journal data
- Use synthetic or anonymized examples only

## Support
This repo is best-effort. For product support, use Reflection's official support channels.
